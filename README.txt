HADICHA SAYTI — TELEFON VA KOMPYUTERGA MOS

1. Saytni tekshirish:
   index.html faylini brauzerda oching.
   Telefonda tekshirish uchun ZIPni telefoningizga yuborib, chiqarib oling.

2. GitHub Pages orqali internetga joylash:
   - github.com saytiga kiring va akkauntingizga kiring.
   - New repository tugmasini bosing.
   - Repository nomini, masalan, hadicha-sayt deb yozing.
   - Public tanlang va Create repository bosing.
   - Ushbu papkadagi index.html, style.css, script.js va images papkasini
     repository ichiga yuklang (fayllarni ZIP holida emas, chiqarilgan holda).
   - Settings > Pages bo‘limiga kiring.
   - Build and deployment qismida Deploy from a branch ni tanlang.
   - Branch: main, folder: /(root) ni tanlab Save bosing.
   - Bir necha daqiqadan so‘ng Pages sahifasida saytingiz manzili chiqadi.

3. Telegram orqali yuborish:
   - GitHub Pages bergan https://...github.io/... manzilini nusxalang.
   - Telegram chatiga yuboring. Havolani bosgan odam saytni ochadi.

MUHIM MAXFIYLIK ESLATMASI:
GitHub Pages sayti internetda ochiq bo‘ladi. Rasmlarni joylashdan oldin
suratdagi insonning roziligini oling. Xohlasangiz, rasmlarni olib tashlab
ham saytni e’lon qilishingiz mumkin.

Bu versiyada musiqa qo‘shilmagan. Rasmlar images papkasida turishi kerak.
